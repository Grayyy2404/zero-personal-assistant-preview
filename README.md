# Zero — Everyday Personal Assistant

**Founded by Graham Temofeh**

Zero is a personal-assistant project focused on everyday organization: planning a day, capturing a thought, and breaking a task into manageable next steps.

This repository is a deliberately limited public preview. It contains a small, browser-only demonstration of the experience and a high-level explanation of the product direction. It is not the full Zero assistant and does not connect to an AI model or external services.

## Try the preview

Open [`index.html`](index.html) in a browser. You can try sample prompts, check off sample tasks, and add temporary notes. The interactions run locally in the page; refreshing it clears the demo state. No account or setup is needed.

## How Zero is intended to work

Zero is designed around a straightforward interaction:

1. You describe an everyday task in your own words.
2. Zero helps turn the request into a useful suggestion, plan, or draft.
3. You review the result and choose what to do next.

See [`docs/how-zero-works.md`](docs/how-zero-works.md) for the high-level product overview.

## What's in this repository

- `index.html` — responsive, offline demonstration page with sample assistant interactions, a temporary checklist, and scratch notes.
- `docs/how-zero-works.md` — a plain-language description of the intended experience and the limits of this preview.
- `.gitignore` — ignores common local secrets and generated files.

The sample responses are fixed examples, not generated by an AI model. This repo has no server, accounts, network calls, or persistent storage. No private assistant source or credentials are included.
