# How Zero works

Zero is a personal-assistant project for ordinary day-to-day tasks. The product direction is to make it easier to move from a thought or request to a clear next step.

## The interaction

```text
Your request → A helpful suggestion or draft → You review and decide
```

You can ask for help organizing a day, capturing a note, or breaking a task into smaller steps. The assistant should respond in plain language and leave the decision with you. For actions that affect something outside the conversation, the intended experience is to show what will happen and let you approve it first.

## What this preview demonstrates

The included page is a small offline prototype. It uses a few fixed sample responses, a temporary checklist, and temporary notes to show the interaction style. It does not use an AI model, create an account, connect to another service, or retain information after the page is refreshed.

## What this document describes

This is a product-level overview, not a description of private implementation details. It does not include the full assistant source, internal configuration, service addresses, data schemas, credentials, or deployment instructions. The limited preview should be evaluated as a concept demonstration, not as a complete or production-ready assistant.
